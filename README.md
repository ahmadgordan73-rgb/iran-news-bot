# ربات خبری مجله نظامی ایران

هر ۱۵ دقیقه خبرهای مرتبط با ایران، ترامپ، اسرائیل و نظامی را از منبع‌های فایل `feeds.json` جمع می‌کند، با هوش مصنوعی جمنای به فارسی می‌نویسد و حداکثر ۳ خبر در کانال تلگرام می‌فرستد.

- برای اضافه یا حذف کردن منبع، فایل `feeds.json` را ویرایش کنید.
- کلیدها در بخش تنظیمات مخزن (Secrets) نگه‌داری می‌شوند.
